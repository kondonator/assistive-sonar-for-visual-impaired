ESP32を使って乾電池（またはバッテリー）の残量（電圧）を取得することは**可能**です。

ESP32に内蔵されているADC（Analog-to-Digital Converter：アナログ/デジタル変換器）機能を使用し、電池の電圧を測定して残量（%）や電圧値（V）としてプログラム側で読み取ります。

乾電池（単四×2本など）やバッテリーの残量を測定する具体的な仕組み、回路構成、コードの書き方、注意点について解説します。

---

### 1. 電池残量測定の仕組み（分圧回路）

ESP32のアナログ入力ピン（ADCピン）は、一般的に **0V 〜 3.3V**（設定によっては 0V 〜 1.1V や 0V 〜 3.1V）の範囲の電圧を読み取ることができます。

* **乾電池2本（昇圧回路を使う場合）の位置:**
* 昇圧コンバータを通した「後の3.3V」を測っても常に3.3Vと表示されてしまうため、昇圧する「前」の乾電池の生の電圧（約2.0V〜3.0V）を測定します。


* **分圧抵抗（Voltage Divider）を入れる理由:**
* 電池が満タンの時や誤って高い電圧（単三3本など）がかかった際にマイコンのピンを破壊しないよう、またノイズを軽減するために、2個の抵抗（例: 10kΩ と 10kΩ、または 100kΩ と 100kΩ）を挟んで電圧を半分にして測定するのが電子工作の安全な定番手法です。



```
【分圧回路の接続イメージ】

  乾電池のプラス (+) ──── [ 抵抗 R1 (100kΩ) ] ┬──── ESP32のADCピン (例: GPIO 34)
                                             │
                                     [ 抵抗 R2 (100kΩ) ]
                                             │
  乾電池のマイナス (-) ──────────────────────┴──── ESP32のGND

```

*※上記のように同じ抵抗値（100kΩ同士）を使うと、ADCピンに入力される電圧は「乾電池の電圧のちょうど1/2」になります。高抵抗（100kΩ）を使うことで、測定回路自体で電池を無駄消費するのを防ぎます。*

---

### 2. 電池残量（電圧）を判別する判定基準

乾電池（アルカリ乾電池 / ニッケル水素充電池）は、使い切るにつれて電圧が下がっていきます。単四電池2本（直列）の場合の電圧変化の目安は以下の通りです。

#### ■ 単四アルカリ乾電池 × 2本（新品：約 3.0V 〜 3.2V）

* **100% (満タン):** 約 3.0V 以上（ADC測定値：1.5V以上）
* **50% (半分):** 約 2.5V 〜 2.7V
* **0% (空・交換時期):** 約 2.0V 〜 2.1V（これ以下になると昇圧回路も動かなくなります）

#### ■ Eneloopなどの充電池 × 2本（満充電：約 2.4V 〜 2.6V）

* **100% (満タン):** 約 2.5V 〜 2.6V
* **0% (空・要充電):** 約 2.0V 〜 2.1V

### 3. Arduino IDE（ESP32）での実装コード例

ESP32の `analogRead()` を使って電圧を計算し、電池残量をシリアルモニタや警告処理に使う例です。

```cpp
const int BATTERY_PIN = 34; // 電圧測定に使うADCピン（GPIO 34など入力専用ピンが最適）

void setup() {
  Serial.begin(115200);
  // ESP32のADC入力範囲の設定（0V 〜 約3.3Vを読み取れる設定）
  analogReadResolution(12); // 12ビット（0〜4095）で取得
}

float getBatteryVoltage() {
  int rawADC = analogRead(BATTERY_PIN);
  
  // ADCの読み取り値を電圧(V)に変換
  // (3.3V / 4095) * rawADC * 2 (1/2に分圧しているため2倍する)
  float measuredVoltage = (rawADC / 4095.0) * 3.3 * 2.0;
  
  return measuredVoltage;
}

void checkBatteryStatus() {
  float voltage = getBatteryVoltage();
  
  Serial.print("電池電圧: ");
  Serial.print(voltage);
  Serial.println(" V");

  // 単四乾電池2本(約2.0V〜3.0V)の残量判定例
  if (voltage < 2.1) {
    Serial.println("【警告】電池残量が低下しています！交換してください。");
    // ここで振動モーターを「ト・ト・ト」と短く3回震わせて視覚障害ユーザーに通知する等の処理を入れる
  }
}

void loop() {
  checkBatteryStatus();
  delay(5000); // 5秒ごとにチェック
}

```

### 4. 視覚障害者向けデバイス（パームソナー2）での活かし方

画面表示（ディスプレイ）を持たないパームソナー2において、取得した電池残量は**触覚（振動）によるフィードバック**に活用できます。

1. **電源ON時の電池残量通知**
* 電源を入れた瞬間に、「ブルッ、ブルッ、ブルッ（3回＝満タン）」「ブルッ（1回＝残りわずか）」のように、振動の回数や長さで手元に電池残量を伝える。


2. **電池切れ前の低電圧警告**
* 測定した電圧が 2.1V を切ったら、通常の障害物検知の振動とは明確に異なる「短く途切れる特殊な警告振動パターン（DRV2605Lの警告波形など）」を出して電池交換を促す。



このように、抵抗2本を足すだけの非常にシンプルな回路追加で、安全かつ利便性の高い電池残量検知機能を組み込むことができます。
