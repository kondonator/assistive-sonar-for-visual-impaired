# パームソナー2（PalmSonar 2）

**パームソナー2（PalmSonar 2）** は、かつて有限会社テイクスより提供されていた視覚障害者用歩行補助具「パームソナー」のコンセプトをベースに、現代の電子工作テクノロジー（ESP32、ToFレーザー距離センサー、ハプティクス振動モジュール）とオープンソースハードウェア（OSHW）の思想を用いて再構築・発展させるプロジェクトです。

* 外部参照リンク：[初代パームソナー 公式サイト（保守資料・設計データ）](https://www.google.com/search?q=https%3A%2F%2Fpalmsonar.com%2Fjp%2F)

---

## 📌 プロジェクトの目的

白杖を用いた単独歩行では、杖先が触れる地表近くの障害物は検知できますが、頭上や胸元・腰の高さにある障害物（飛び出した看板、木の枝、トラックの荷台など）の回避には限界があります。

パームソナー2は、従来の白杖による接触検知を補完し、**「頭上から足元までの空間障害物を非接触かつ高精度にセンシングし、直感的な触覚（振動）フィードバックで伝える」** ことを目指しています。

さらに本プロジェクトでは、誰もが持続可能かつ安価に入手・保守できるよう、**設計書・3Dプリントデータ・ファームウェアを完全オープン化**し、手軽な電子部品を組み合わせることで個人で自作・カスタマイズできる環境を提供します。

---

## 🚀 特長と主要コンポーネント

* **高精度な空間距離計測:** 最新の ToF（Time-of-Flight）レーザー距離センサー（VL53L1X 等）を採用し、最大4m先の障害物との距離をミリメートル単位で計測。
* **直感的な触覚フィードバック:** ハプティクス制御IC（DRV2605L 等）による多彩な振動パターンを用いて、障害物との距離や危険度を手に伝達。
* **オープンハードウェア ＆ 低コスト:** ESP32 マイコンと汎用モジュール、3Dプリンタ製筐体を用いることで、高いパフォーマンスと低価格化（数千円〜1万円程度でのセルフビルド）を実現。
* **多様な装着アプローチの検討:** 白杖一体型アタッチメント、胸元・ウェアラブル装着、スマートグラス連携など、片手をフリーに保つ柔軟なインターフェース設計。

## 🛠 ハードウェア構成（最小構成 / PoC）

| コンポーネント | 推奨パーツ / 型番 | 備考 |
| --- | --- | --- |
| **マイコンボード** | ESP32-DevKitC V4 (ESP-WROOM-32E 搭載) | Wi-Fi / Bluetooth 対応、USB給電・プログラミング |
| **ToF 距離センサー** | VL53L1X 搭載モジュール (Pololu 3415 等) | 最大 4m 計測、I2C 通信 |
| **振動制御 / モーター** | DRV2605L 搭載モジュール ＋ コイン型振動モーター | 触覚フィードバック制御 |
| **ブレッドボード / 配線** | サンハヤト SAD-101 / EIC-801 等 ＋ ジャンパーワイヤ | 卓上実験用 (ハンダ付け不要) |

## 💻 開発・動作環境

* **対応OS:** macOS / Linux / FreeBSD / Windows
* **開発ツール:** Arduino IDE 2.x / PlatformIO
* **必要ライブラリ:**
* `VL53L1X` (Pololu / STMicroelectronics)
* `Adafruit_DRV2605` (Adafruit)
* `Wire` (Arduino 標準 I2C ライブラリ)

## 🚦 マイルストーン（ロードマップ）

1. **[施行中] Milestone 1: 卓上 PoC (概念実証)**
* ブレッドボード上でのパーツ接続と ESP32 ファームウェアによる基本機能（距離測定 → 振動出力）の検証。


2. **Milestone 2: ウェアラブル化 ＆ 筐体デザイン**
* バッテリー駆動化と、3Dプリンタによる「白杖取り付け型 / ハンズフリー型」ケースの設計・試作。


3. **Milestone 3: 実証実験 ＆ 振動アルゴリズムのブラッシュアップ**
* 歩行時の安全性を担保するためのセンシング精度・振動フィードバックのチューニング。


4. **Milestone 4: ドキュメント化 ＆ リリース**
* BOM（部品表）、回路図（KiCad）、3Dモデルデータ（STL/STEP）、初心者向け組み立てガイドの公開。
